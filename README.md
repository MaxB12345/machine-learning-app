# ML Mastery

An offline-capable PWA for practising a Machine Learning module with a source-cited question bank
(8 question types, spaced repetition, maths rendered with KaTeX). Static files, no build step.

## Using it
Open the GitHub Pages site on your phone, then Share > Add to Home Screen. After the first load it
works offline. Progress is stored on the device; use Stats > Export progress to back it up.

## Layout
- `docs/`: the site (GitHub Pages: branch `main`, folder `/docs`)
  - `data/questions.json`: generated by `tools/build.py`, do not edit by hand
  - `js/`: small ES modules (`types/` holds one renderer per question type)
  - `sw.js`: service worker; `CACHE_NAME` is rewritten by `npm run bump-cache`
- `content/questions/week_N/*.json`: the question bank (source of truth)
- `content/extracted/`: page-numbered lecture text, **gitignored**, regenerated by `tools/extract.py`
- `tools/`: extract, validate, build and deploy scripts (Python)
- `tests/`, `scripts/`: Node tests and the cache-version script

## Question rules
Every question cites `file`, `page` and a verbatim `quote`. `tools/validate.py` fails unless the quote
appears (whitespace-insensitive) on that page of the extracted source. Quotes are stripped from the
shipped `questions.json`, which only keeps file and page references.

## Setup
    python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt

The course material (slides, worksheets, notebooks) lives in a separate private repo, expected at
`../machine-learning`. Set `ML_COURSE_REPO` to use another path.

## Adding content
1. Put new material in the course repo under `week_N/`.
2. `.venv/bin/python tools/extract.py`
3. Write or edit `content/questions/week_N/*.json`.
4. `.venv/bin/python tools/deploy.py` validates, builds, runs tests and bumps the cache version.
   Add `--push` to commit and push, which publishes the site.

## Commands
    npm test            unit tests
    npm run serve       serve docs/ at http://localhost:8000
    npm run bump-cache  update the service-worker cache name from a content hash
